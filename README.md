# AI_assisted_job_application
AI-assisted job application tool developed as a Business Analysis and AI project.

## Project Overview
This project explores how AI can support university students,
graduates and early-career job seekers in preparing more targeted
job applications.

## Business Problem
Job seekers often find it difficult to understand how their skills
and experience align with a specific job opportunity and how their
resume should be tailored accordingly.

## Objectives
- Improve job-role alignment
- Support more targeted job applications
- Improve application quality and consistency
- Reduce application preparation effort
- Maintain user ownership of AI-generated content

## MVP
The MVP enables users to:
- Upload a resume
- Enter a Job Description
- Analyse job fit
- Identify strengths and gaps
- Receive resume improvement recommendations
- Generate a tailored cover letter

## Solution
The application connects a web-based interface with an AI model
through an API.

Resume + Job Description
→ AI Analysis
→ Job Match
→ Strengths & Gaps
→ Resume Recommendations
→ Cover Letter

## Change / Enhancement
Following the initial V2 implementation, a change was introduced
to allow users to select a preferred cover letter tone:

- Professional
- Concise
- Enthusiastic

An impact analysis was conducted before implementing the change.

## UAT
The solution was tested against the key user journey and business
requirements, including resume input, job analysis, resume
recommendations, cover letter generation and tone selection.
